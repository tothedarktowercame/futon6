# a96J06 publication telling

## Publication

**[B1]** Fix \(r>0\), and suppose that \(\lVert p(z)\rVert\le r\) whenever
\(\lVert z\rVert<r\).

**[B2]** Define \(g(w)=r^{-1}p(rw)\), thereby transferring this supposition to
the unit disk while preserving \(g(0)=0\) and \(g'(0)=1\).

**[B3]** If \(\lVert w\rVert<1\), then \(\lVert rw\rVert<r\), whence
\(\lVert g(w)\rVert\le1\); moreover, \(g\) is holomorphic on the unit disk.

**[B4]** The complex Schwarz equality case, applied using this holomorphy, the
map into the closed unit disk, \(0\) in the domain, and
\(\lVert\operatorname{dslope}(g,0,0)\rVert=1\), yields
\(g(w)=g(0)+w\operatorname{dslope}(g,0,0)\); since \(g(0)=0\) and
\(\operatorname{dslope}(g,0,0)=g'(0)=1\), we obtain \(g(w)=w\) on the unit
disk.

**[B5]** Rescaling back gives \(p(z)=z\) throughout the radius-\(r\) disk.
Because this disk is infinite, equality of evaluations implies the polynomial
identity \(p=X\).  Applying the degree-\(N\) coefficient map gives
\(c_N=\operatorname{coeff}_N(X)=0\), since \(N\ge2\).

**[B6]** This contradicts \(c_N\ne0\); hence the supposition is false, and for
every \(r>0\) some \(\zeta\) satisfies \(\lVert\zeta\rVert<r\) and
\(\lVert p(\zeta)\rVert>r\).
