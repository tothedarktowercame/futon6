# GOLDEN-30 quality checklist — typewise review (DP discipline)

Distributed Proofreaders work per TYPE, not per page (Joe, 2026-06-12).
Review each type across ALL pages before judging any page. Reference
standard: golden-paragraph.html (operator-approved) + the two Fable
workups (0809.2517, 2310.17349; fable-workup-golden30.edn).

- **T1 source integrity** — damage repaired evidence-based (attestation
  counts logged); no over-repair; repair log present even when empty.
- **T2 definition mining** — definienda found per env; SPAN discipline:
  the term only, not its conditional clause or surrounding phrase.
- **T3 occurrence coverage** — every occurrence of each definiendum
  marked; no unmarked uses after the definition.
- **T4 hole honesty** — amber = plausibly a MATH CONCEPT lacking
  in-paper definition. Precision over recall, hard rule: an amber mark
  containing a verb phrase or sentence fragment is an over-mark.
- **T5 bind correctness** — symbol boundaries exact ("that's not a
  thing" test); type text is a type, not prose.
- **T6 expression layer** — math construct marks never cut tokens.
- **T7 title card fidelity** — present on every page; signature matches
  the paper's actual subject; census verifiable by hand count.
- **T8 plot/structure** — env sequence matches the paper's real
  structure; nesting depths sane.
- **T9 render integrity** — valid HTML; spans never break TeX tokens;
  legend complete; links resolve.
- **T10 the glance test (operator)** — can a reader tell what the paper
  is about from the card alone?
- **T11 artifact classification** — non-article items (e.g. 0506470
  "Files for Gabriel-Zisman localization", a file compendium) must be
  CLASSIFIED as artifacts, not anatomized as failed papers.
