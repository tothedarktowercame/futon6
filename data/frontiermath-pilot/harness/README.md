## Instances

Generated by `scripts/fm001/ramsey_book_sat.py`, which encodes: is there a
2-colouring of $K_{4n-2}$ whose red graph avoids $B_{n-1}$ and whose blue graph
avoids $B_n$? A SAT witness refutes $R(B_{n-1}, B_n) \le 4n-2$ for that $n$.

| instance | vertices | vars | clauses | notes |
|---|---|---|---|---|
| `FM001-n5.cnf` | $K_{18}$ | 18 360 | 48 976 | includes the vertex-0 symmetry breaker |
| `FM001-n6.cnf` | $K_{22}$ | 41 580 | 106 280 | mission note said 106 260 — see Corrections |

### Reproduction — both are byte-identical

    .venv/bin/python scripts/fm001/ramsey_book_sat.py 5 --cnf-out /tmp/n5.cnf --no-solve
    .venv/bin/python scripts/fm001/ramsey_book_sat.py 6 --cnf-out /tmp/n6.cnf --no-solve
    cmp /tmp/n5.cnf $STORAGE/FM001-n5.cnf   # -> no output: identical
    cmp /tmp/n6.cnf $STORAGE/FM001-n6.cnf   # -> no output: identical

Confirmed 2026-08-20: the generator is deterministic and still reproduces both
stored CNFs exactly, so the hashes below pin a rebuildable artifact rather than
an orphaned blob.

## Witness verification

The stored witnesses were checked against the harness's own
`verify_assignment`, which rejects a colouring if any edge carries $\ge n-1$ red
support or $\ge n$ blue support:

| witness | n | complete graph | edges | verifies |
|---|---|---|---|---|
| `n3-witness.json` | 3 | $K_{10}$ | 45/45 | yes |
| `n4-witness.json` | 4 | $K_{14}$ | 91/91 | yes |
| `n5-witness.json` | 5 | $K_{18}$ | 153/153 | yes |

Reproduce by loading a witness, mapping `red_edges`/`blue_edges` through
`ordered_pair`, and calling `verify_assignment(n, vertex_count, assignment)`.
All three return `True` on a complete edge set, so the n=3/4/5 refutations rest
on checked counterexamples rather than on solver say-so.
